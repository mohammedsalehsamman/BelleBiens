# ADR 0005: الخادم هو مرجع السعر

- **الحالة:** مقبول · 2026-11-11 · S0
- **القرار:** الخادم يحسب كل سعر ويتجاهل أي سعر من العميل (NFR-SEC-06؛ `forbidNonWhitelisted` يرفض الحقول غير المعروفة). التطبيق يحسب تقديراً فورياً بنفس قواعد المتجهات (NFR-PERF-03: 200ms) ثم يطلب quote بعد توقف قصير؛ قيمة الخادم هي المعتمدة.
- **قواعد مقترحة تحتاج تأكيد المحل:** الكوبون قبل رسوم التوصيل، والتحويل للدولار لكل بند ثم الجمع، والتقريب على الإجمالي فقط.
