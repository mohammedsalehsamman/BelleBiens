# ADR 0007: معاينة 3D داخل WebView (R3)

- **الحالة:** مقبول مبدئياً · يُثبَّت بنموذج أولي قبل S10 (القرار D-05)
- **القرار:** عارض واحد (Three.js/R3F) في `packages/viewer3d` يستخدمه الموقع والتطبيق؛ التطبيق يضمّنه في `webview_flutter` مع جسر JS يمرر الـ spec. خفض الجودة تلقائياً والرجوع إلى 2D (FR-D3D-06).
