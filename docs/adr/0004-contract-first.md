# ADR 0004: العقد أولاً ومتجهات اختبار مشتركة

- **الحالة:** مقبول · 2026-11-11 · S0
- **القرار:** `packages/contracts` هو المرجع: `openapi.yaml` مولّد من الـ API ويفشل الـ CI إذا اختلف، ومخططا bouquet/box spec بصيغة JSON Schema، ومتجهات (التسعير، التطبيع العربي، الهاتف، hash الـ spec) يجب أن يعيد إنتاجها الخادم والتطبيق حرفياً.
- **النتائج:** `src/reference.mjs` يثبت أن المتجهات متسقة فقط؛ لكل طرف تنفيذه الخاص. سلة README (7,266 ل.س / $60.55) متجه ذهبي.
