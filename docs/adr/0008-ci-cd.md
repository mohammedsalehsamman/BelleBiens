# ADR 0008: CI/CD

- **الحالة:** مقبول · 2026-11-11 · S0
- **القرار:** GitHub Actions لفحوص كل PR (`api.yml` و`mobile.yml` و`contracts.yml` و`security.yml`)، وCodemagic لبناء التطبيق وتوزيعه (`codemagic.yaml`). نشر الـ API إلى staging يُضاف بعد اختيار الاستضافة (OI-04). الإنتاج بموافقة يدوية (المخطط 11).
