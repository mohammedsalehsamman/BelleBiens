# Belle Biens — واجهات تطبيق الموبايل (نسخة HTML)

كل مجلد فيه `code.html` لشاشة واحدة بعرض 390px، بنفس أسلوب مجلدات Stitch. افتح `index.html` لتتنقل بين الشاشات؛ الروابط بين الشاشات شغّالة.

## قرارات عامة

- الأسعار أمثلة موحّدة بالليرة السورية الجديدة (بعد حذف الصفرين في 1/1/2026)، وسعر صرف مثال 120 ل.س للدولار. المحل يحدد الأسعار الحقيقية.
- مثال سلة واحد يمر بكل الشاشات: باقة مصمّمة 2,676 + لاتيه ×2 1,080 + كيكة 22 سم مع شمعة 3,360 = 7,116 ل.س، وتوصيل أبو رمانة 150، والإجمالي 7,266 ل.س (≈ $60.55).
- أرقام غربية (1, 2, 3) افتراضياً، والهندية خيار من الإعدادات (FR-LOC-02).
- شريط التنقل: الرئيسية، المتجر، صمّم باقتك، طلباتي، حسابي.
- شيلنا الادعاءات غير المؤكدة (توصيل مبرّد، قطاف المزارع، متجر مرخّص، دمشق القديمة، ضمان النضارة، سرعة الرد) والتقييمات المكتوبة يدوياً.
- النصوص بين [ ] أماكن لمعلومات يعطيها المحل.
- تعديلات تباين: نص الشارات الخضراء والكهرمانية أغمق من DESIGN.md الأصلي حتى يحقق WCAG AA (4.5:1)، ولون النص الثانوي #605856.
- الأيقونات SVG مضمّنة بدل خط Material Symbols، والصور من روابط Stitch الأصلية (تحتاج إنترنت).
